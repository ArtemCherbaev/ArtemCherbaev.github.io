How this page works

From a push to this page

The suite's pipeline builds one execution image, runs the four lanes in it in parallel, and publishes the reports together with a small run feed: every case, its outcome, when it started within its lane and how long it took. This page reads only that feed, from the same site, and draws the run from it.

The feed has a versioned format the pipeline checks before it publishes. A report that would not fit it fails the publish and leaves the previous one up, so this page never has to guess at a shape it was not built for — and if the feed is unreachable, the page falls back to the reports rather than to numbers nobody measured.
