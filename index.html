05 / APPROACH

A few things
I take seriously.

The decisions behind the tests
matter as much as the code.

01

Start with the risk.

Review requirements and acceptance criteria before development. Use test-design techniques and exploratory testing to cover the failures that matter.

02

Follow the evidence.

Read the traces, inspect the requests, and validate the data. Find the responsible layer before changing a test or calling a failure flaky.

03

Make quality repeatable.

Build clear release gates and reliable test setup. Use AI to support the work, and review the changes against the behavior the product needs.
